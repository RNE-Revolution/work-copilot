FAQ disclosure list. Each row toggles; the "+" chip rotates 45° and flips to green when open. Single-open behaviour.

```jsx
<Accordion items={[
  { q: 'Was ist GGV?', a: 'Gemeinschaftliche Gebäudeversorgung …' },
  { q: 'Wer kann mitmachen?', a: 'WEGs und Eigentümergemeinschaften …' },
]} defaultOpen={0} />
```
